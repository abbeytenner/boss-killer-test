# Boss Fight Test

## Overview

A simple multi-phase boss fight.

### Phase 1
The boss has two arms:
- **Claw** — swipes and stabs at you
- **Mini-gun** — shoots at you periodically

Shoot off both arms to damage the head.

**On Hard**
- **Sawblade** — does a sweeping attack around the arena's perimeter
- **Cannon** — lobs projectiles upwards that detonate into three smaller projectiles

### Phase 2
The head now:
- Charges at you
- Performs a sweeping attack that laps around the arena

### Phase 3
The head limps around, trying to dodge your attacks while shooting projectiles.

---

## Difficulties

| Difficulty | Description |
|------------|-------------|
| **Normal** | Baseline difficulty |
| **Easy**   | Gives you more time to react (functionally the same as Normal) |
| **Hard**   | Adds two extra arms and makes the boss attack faster |
